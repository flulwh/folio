# 性能

Folio 的性能目标很具体：**打开一本 30 万字以上的书，一秒内能读**。这条目标驱动了下面所有的取舍。

本文记录实测数据与背后的机制。README 只给结论。

---

## 一、实测基线

一本 **37 万字、5600 段**的长篇，Ryzen 笔记本 / Electron 30：

| 场景 | 首开 | 文字出现 | 复开 |
| --- | --- | --- | --- |
| 打包版（生产压缩） | 1035ms | 576ms | 543ms |
| 开发模式（`npm run dev`） | 略高（无生产压缩） | — | — |

打包版从上次位置恢复的误差 24px（文档总高 45 万 px）。

---

## 二、虚拟滚动

几百万字的长篇也只渲染视口附近的段落，滚动不掉帧。

自研 `src/hooks/useVirtualScroll.js`：变高段落 + 二分定位 + `ResizeObserver` 重测。

**分块测量**是这里最关键的一环：

- 打开书时先精确量一遍每段高度（虚拟滚动依赖真实高度，否则滚动会跳）
- 5600 段一次性塞进 DOM 要冻结 1.8 秒
- 现在每帧只铺 600 段，量完用 `requestAnimationFrame` 让位给浏览器绘制
- 首屏文字 **843ms** 就出现，顶部显示「正在排版 42%」，可读的区域先可读

---

## 三、高度缓存

量完把 `{栏宽, 每段高度}` 存进 localStorage，键 = 书 ID + 字号 + 行距 + 宽度 + 段距 + 字体 + 缩进 + 段数。

下次打开直接复用：**复开 720ms**（原来 1533ms 且全程卡住）。

**缓存不盲信**：先用真实 DOM 量第一批，和缓存逐段比对，偏差 > 2% 就丢弃重测 —— 字体没加载完、窗口宽度变了都会命中这条回退。

## 四、书源引擎

| 优化 | 效果 |
| --- | --- |
| **书源列表瘦身** | 书源 JSON 里有 `jsLib`（每个源几十 KB 脚本）和全部规则文本。370 个源一次 IPC 传输 1.54MB、耗时 37ms。现在列表只传轻量字段（`id/name/host/group/enabled/stat/hasSearch/unsupported`），体积降到 **92KB（-94%）**、耗时 20ms；规则仍留在主进程，改开关不会再写回整表 |
| **写盘合并** | 书源文件 1.6MB，过去每次试搜都整表重写。现在内存常驻 + 300ms 防抖 + 退出前 flush，连续试搜只落盘一次 |
| **搜索配额** | 几百个源时全量搜索要 41 秒。现在按健康度取前 24 个并发搜（3 路），3 秒内出结果，剩下的可点「搜索全部」 |
| **懒加载** | `electron/sources.js` 有 111KB（外加 html/xpath/jsengine 一条依赖链），拆出独立的 `cloudstore.js` 后整体懒加载 —— 主进程启动时不必解析那 300KB |

## 五、渲染层

- Vite 手动分包 + 路由级懒加载
- Context 细粒度拆分：书架 / 阅读器 / 设置 / 日志各自订阅自己需要的状态
- 主题令牌只写一份：`src/design/tokens.css` 是唯一真相来源，`src/themes.js` 保留一份用于设置页预览卡与运行时注入；两份由 `npm run check:theme` 核对

---

## 六、动效性能

动效在低端机上掉帧比没有动效更糟，所以：

- 骨架屏、进场动画统一走 `src/motion-kit.js`，皮肤只决定参数，不允许组件自带动画
- 滚动与过渡遵守 `prefers-reduced-motion`，设置里还有「减弱动效」开关
- 缓动滚动自研 rAF 而非 `scroll-behavior: smooth` —— 原生平滑滚动时长不可控、也无法在滚轮介入时干净地被打断

详细见 [motion.md](motion.md)。

## 七、回归工具

`tools/` 下这批脚本是性能与动效的守门人，不靠肉眼判断：

| 工具 | 作用 |
| --- | --- |
| `_boot-race.cjs` | 统计启动白屏率 |
| `_feel.cjs` | 逐帧量化动效（时长、位移、是否掉帧） |
| `_settings-blank.cjs` | 切皮肤后分区空白的回归 |
| `_lan-check.mjs` | 局域网服务端 46 项断言（不依赖 Electron） |
| `_lan-panel-shot.cjs` | 端到端：真浏览器开面板 → 读书 → 进度写回磁盘 → 桌面端接住（18 项） |
| `_lan-cloud-shot.cjs` | 云端书：目录、阅读、翻章、跳章、进度写回（22 项） |
| `_theme-sync.mjs` | 主题令牌两份副本一致性 |
| `_scope-skin.mjs` | 由 `src/miui.css` 生成作用域化的 `src/skin-miui.css` |
